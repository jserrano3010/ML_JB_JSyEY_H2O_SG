# Jupyter Book — Yunis Serrano

Esta carpeta contiene la versión HTML construida del Jupyter Book, preparada para publicarse como sitio estático en GitHub Pages.

## Publicación

Sube **el contenido de esta carpeta** al repositorio de GitHub y configura GitHub Pages para publicar desde la rama principal (`main`) y la carpeta raíz (`/`).

El archivo `.nojekyll` permite que GitHub Pages sirva correctamente los recursos generados por Sphinx/Jupyter Book.
